# Media assets

Add the following files before publishing the repository:

- `handwriting-demo.gif`: short loop of the simulated handwriting motion.
- `handwriting-path.png`: target and traced end-effector path.
- `workspace.png`: OXY/OXZ workspace visualization.
- `ik-branches.png`: elbow-up and elbow-down inverse-kinematics solutions.

Keep GIF files below roughly 10 MB for fast rendering on GitHub. Host the full-resolution video externally and link it from the main README.
